# Glass Browser
Safari/iOS-style liquid-glass browser for Android (WebView + HTML glass UI in app/src/main/assets/ui.html).
1. Upload this folder's contents to a new GitHub repo (branch main).
2. Open Actions > Build APK > wait for green.
3. Download the artifact GlassBrowser-debug-apk and install the APK.
AI uses the free Pollinations text API (no key).
